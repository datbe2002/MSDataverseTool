SQL tool

Query Dataverse like a database.

  • Reads every table. A built-in FetchXML engine runs your SELECT, reading big tables in parallel; the TDS endpoint is there when you need it.
  • Results as they arrive. Rows stream into the grid page by page, with timings that show where the time went.
  • Safe writes. INSERT, UPDATE and DELETE show how many records change and ask before sending anything.
  • Editor you know. Monaco (the VS Code editor) with table and column completion, tabs and history.
SELECT TOP 100
       a.name, a.revenue, c.fullname
FROM   account a
JOIN   contact c ON c.contactid = a.primarycontactid
WHERE  a.statecode = 0
ORDER BY a.revenue DESC

Flows tool

Understand any cloud flow in minutes.

  • Every flow in the environment. Filter by owner, solution and status — straight from Dataverse, no extra permissions.
  • A designer view. Steps in run order, parallel branches side by side, conditions and switches as columns.
  • Follow the data. See where each variable is declared, changed and read, which steps read an output, and jump between them.
  • Child flows and search. Open child flows, find who calls a flow, and search steps by name or by what they contain.

Designer
